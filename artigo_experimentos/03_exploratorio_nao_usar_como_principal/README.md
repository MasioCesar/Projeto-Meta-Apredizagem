# Exploratorio - Nao Usar Como Principal

Esta pasta contem testes que ajudam a entender o comportamento do sistema, mas
nao devem ser a base da conclusao do artigo.

Motivos comuns:

- desempenho inferior;
- maior risco de vazamento;
- mudanca simultanea de muitas variaveis;
- resultados uteis apenas como diagnostico.

Experimentos aqui podem ser mencionados brevemente, se necessario, mas a
narrativa principal deve usar a pasta `01_usar_no_artigo`.
