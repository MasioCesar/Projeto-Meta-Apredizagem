# LLM - Parcial / Trabalho Futuro

Os scripts desta pasta testam features extraidas por LLM.

Nao usar como resultado principal neste artigo porque a geracao ficou parcial.
A chamada online encontrou limites de taxa/cota e apenas parte dos datasets
recebeu features LLM reais.

Uso recomendado:

- citar como possibilidade de trabalho futuro;
- repetir futuramente com uma API/cota estavel;
- comparar com o modelo por clusters semanticos.
